# Roadmap

Where OpenDot is heading. These are directions, not promises or dates. If something here matters to you, say so in
[Discussions](https://github.com/athulsreekumar/opendot/discussions) or pick it up: see [CONTRIBUTING.md](CONTRIBUTING.md).

## Now

- **Signed and notarized builds**, so macOS doesn't warn on first launch.
- **A first tagged release (v0.1.0)** with DMGs on GitHub Releases.
- **More Dot templates** contributed by the community.
- **Better first-run experience**: clearer model setup and a guided first Dot.

## Next

- **Homebrew cask** (`brew install --cask opendot`).
- **Automatic updates** for installed builds.
- **Push instead of polling** for Gmail and Outlook where it's possible without a public server (today they're
  checked every 30 seconds).
- **More connectors** in the catalog (Notion, Linear, Slack, GitHub) with one-click setup.
- **Shareable Dots**: export a Dot's personality, tools and rules as a file someone else can import.

## Later

- **Local voice**: talk to your Dots, with speech recognition on the Mac.
- **Shortcuts and Siri** actions for asking a Dot or SuperDot.
- **A plugin API** for custom watchers and native tools.

## Not planned

- **Windows and Linux apps.** OpenDot is built around the Mac: the Keychain, Calendar, Reminders, Notes and
  AppleScript. Contributions that keep the core portable are still welcome.
- **A hosted cloud version.** OpenDot is local-first by design.
