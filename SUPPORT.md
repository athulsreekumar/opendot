# Getting help

| You want to… | Go here |
|---|---|
| Ask a question or share how you use OpenDot | [GitHub Discussions](https://github.com/athulsreekumar/opendot/discussions) |
| Report a bug | [Bug report](https://github.com/athulsreekumar/opendot/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/athulsreekumar/opendot/issues/new?template=feature_request.yml) |
| Report a security problem | [Privately, via GitHub](https://github.com/athulsreekumar/opendot/security/advisories/new). See [SECURITY.md](SECURITY.md) |
| Build or install OpenDot | The [README](README.md#build-it-yourself) and [opendot.live/download](https://opendot.live/download) |
| Set up Google, Microsoft or MCP | [`desktop/README.md`](desktop/README.md) and the [guides](https://opendot.live/guides) |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before opening an issue, please search existing issues and check the
[known limits](desktop/README.md#known-limits-v01).

When you report a problem, `~/.opendot/logs/main.log` usually tells us what went wrong. Remove anything personal
before you share it.
